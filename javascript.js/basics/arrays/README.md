Arrays Exercise

Run the example with Node:

```
node exercize.js
```

What it shows:

- Creating arrays and reading `length` and `indexOf`.
- Using `slice`, `push`, `pop` safely on copies.
- `map`, `filter`, `find`, `includes`, `sort`, `join`.
- `reduce` to compute sums and find the longest string.
- Accessing a 2D array (matrix) and `forEach` iteration.

Open `exercize.js` to explore and modify examples.
